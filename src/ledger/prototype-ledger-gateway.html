LedgerGuard Gateway Prototype [PROTOTYPE — in-memory, no persistence]

Throwaway logic demo for POST /api/ledger/transfer + GET /api/ledger/balance behind authenticate/rateLimiter. State lives in memory. Run by opening this file. Nothing here is production.

Tenant Isolation — second tenant's ledger is isolated from the first's

Create two tenants (qf_*) via TenantStore, fund alice/USDT for each tenant separately, transfer in tenant A, verify tenant B balance unchanged.

Double-Spend — strict per-account serializable

Account alice/USDT balance 100 v5. Two concurrent debit 60 with expectedVersion=5. Only one may succeed.

Idempotency — same key returns same Transaction

Retry POST /transfer with same Idempotency-Key must not double-debit.

Fencing — stale lock holder fenced

Holder A acquires ledger:lock:{tenant}:{account} (fence 1), stalls past TTL, holder B acquires fence 2. A's delayed produce with fence 1 must be rejected on materialize.
