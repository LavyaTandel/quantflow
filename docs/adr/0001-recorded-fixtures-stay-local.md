# Recorded exchange fixtures stay local; the repo carries only normalized or synthetic data

Exchange terms make committing raw market data legally hazardous: Coinbase's Market Data Terms of Use (§3.2) prohibit redistributing data or derived works, and OKX's API Agreement (§9.4) extends its redistribution ban even to unauthenticated public-endpoint data; Binance publishes bulk archives openly but without a clean explicit license for redistribution. We therefore commit only venue-neutral normalized events or synthetic generators, and record real captures exclusively into gitignored `.local-fixtures/`. Consequence: CI never depends on live sockets, and any clone reproduces tests without legal exposure. This is recorded because reversing it after raw bytes enter public git history is practically impossible.
